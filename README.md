# Matching Engine: Go vs Rust

Движок матчинга лимитных ордеров на Go и на Rust с одинаковой семантикой,
одинаковым потоком ордеров и одинаковым протоколом замера.

![Протокол автора, 5 раундов: Go 37.8 M ордеров/с против Rust 103.5 M — x2.7](benchmark-5-rounds.svg)

Замер по протоколу автора (`WARM=1 ROUNDS=5 ./run_benchmark.sh`, Apple M4):
в установившемся режиме Go даёт 2.65 ms на 100 000 ордеров (37.8 M ордеров/с),
Rust — 0.97 ms (103.5 M ордеров/с), **Rust быстрее в 2.7 раза**; сделки и объём
у обеих сторон совпадают (77 576 / 1 973 216). Код Go не изменён.

## Запустить у себя

Нужны Go 1.21+ и Rust 1.85+ (на macOS Go ставится через `brew install go`).

Как в оригинале — сначала Go, потом Rust, без сети, протокол автора с обеих
сторон (прогрев 10k, 5 итераций по 100 000 ордеров, среднее):

```bash
./run_benchmark.sh
```

С холостым прогоном обоих бинарников перед замером и пять раундов подряд,
чтобы видеть разброс, а не одно случайное число (первый запуск процесса после
простоя на Mac идёт вдвое медленнее, и 5 итераций целиком в него попадают):

```bash
WARM=1 ROUNDS=5 ./run_benchmark.sh
```

Расширенный замер Rust — 101 итерация, публикуются min / median / p95 / p99:

```bash
cd rust && cargo run --release --bin matching-engine-rust -- --iters 101
```

Тесты и линтер:

```bash
cd rust && cargo test --release && cargo clippy --all-targets -- -D warnings
```

Перед замером — `uptime`: при `load average` выше ~4 числа плавают.
